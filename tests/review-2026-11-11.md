## Executed checks

- Repository YAML/layout/index/link validation finds **21 skills**.
- Skills CLI **1.7.6**, already cached locally, discovered the repository and installed
  each of `1-discover`, `4-analyze` and `5-publish` into fresh temporary agent directories.
  Installed counts were 2, 5 and 3; the five new names appeared without duplicates.
- Statistics: **6 tests**, including finite/invalid/infinite/missing values, all-null and
  empty inputs, leading-zero/literal-NA categories, JSON/CSV round trips, overwrite refusal,
  unchanged source data and a known 100 m² square measured from projected/geographic inputs.
- Aggregation: **8 tests**, including independent expected counts/sums/means, boundary and
  overlap policies, duplicate DataFrame indices, unmatched/empty zones, known mixed CRSs,
  invalid inputs, zero denominators and real GeoPackage/CSV round trips.
- BD TOPO: **5 tests** cover field semantics, source/page provenance, explicit aliases,
  unsupported model/revision/format/field handling and offline lookup without network.
- QGIS: **15 tests** ran on existing local **3.44.9** and in dedicated **3.34.4** CI. They
  cover real QML and project artifacts, renderer boundaries, units, categories/nulls,
  vector/raster composition, layer-tree state, QML reuse, relocation with the original
  location removed, source-directory inventory, WMTS URI semantics and controlled remote
  failure. Missing PyQGIS fails the dedicated job rather than silently skipping it.
- The full offline suite ran in the existing geospatial environment: **160 tests**, with
  **25 expected skips** for optional/live capabilities, including the two QGIS test classes
  exercised separately. GitHub CI provisions its own geospatial/QGIS workers.

No local software was installed. Existing environments required explicit matching PROJ/GDAL
paths; the initially broken default environment was not treated as a skill failure.

## Defects found and corrected

1. QGIS custom graduated-label formatting changed a flag during QML reload. The helper
   now sets it explicitly; renderer equality and exact-break checks pass on both versions.
   Historical red workflow runs for PR #50 predate this fix; current heads pass.
2. QGIS considered aligned-point extents empty, excluding a distant point from the default
   view. The project helper now unions degenerate bounds explicitly; XP-13 rerun confirms
   the automatic extent covers all objects.
3. A bare WMTS endpoint was interpreted as WMS; generic URL encoding then also escaped
   CRS/format scalars incorrectly. The helper now uses a full capabilities URL through
   `QgsDataSourceUri` and checks provider CRS. A regression checks the provider URI, and
   a separate live run used the **final helper** to build/reopen a project and render
   Plan IGN alone and with the Saint-Mandé boundary. Both renders had 6,396 nonwhite
   samples out of 6,400, no renderer errors, and were visually checked.
4. Raster inspection can write GDAL auxiliary statistics beside source files. The project
   helper disables PAM during its reads and restores the prior setting. Tests verify
   both source bytes and directory inventory, including with PAM initially enabled.
5. The official BD TOPO PDF URL now serves model 3.5 **revised July 2026**. The guide pins
   this revision/hash and source pages; it does not conflate that revision with a delivery
   edition or assume WFS names. The zero-height constraint continued on page 77 was checked.

These are **pilots**, not the full 177-run, three-repetition campaign. They demonstrate
routing and artifact behavior on representative requests, not a statistically established
success-rate improvement. Existing global user instructions/tools may affect both modes;
explicit transcript checks do not rule out all inherited knowledge. Live tile availability
is dated evidence and remains outside ordinary offline CI. Broader versions, complex QML
assets, raster styling, print layouts and exhaustive BD TOPO schemas are outside this scope.
