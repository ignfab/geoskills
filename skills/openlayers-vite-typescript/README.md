# openlayers-vite-typescript

Create a clean [OpenLayers](https://openlayers.org/) project with
[Vite](https://vite.dev/) and TypeScript, starting from the official
[ol-vite](https://github.com/openlayers/ol-vite) template.

## Requirements

Node 14+ and `git`.

## Installation

```bash
npx skills add ignfab/geoskills --skill openlayers-vite-typescript
```

## Contents

| File | Purpose |
|------|---------|
| [SKILL.md](SKILL.md) | Project creation, dev server, build, and the TypeScript switch in three steps. |
| [references/typescript-setup.md](references/typescript-setup.md) | Full `tsconfig.json`, `src/main.ts` example, resulting layout, type checking. |

## Example

```bash
npx create-ol-app my-app --template vite
cd my-app
npm install -D typescript
npm start
```
